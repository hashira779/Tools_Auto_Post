# Security Policy

## Supported Versions

At CamTech, we take the security of our tools and services very seriously. We actively maintain the `main` branch of this repository.

| Version | Supported          |
| ------- | ------------------ |
| `main` (Latest) | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within CamTech's services (SaveMedia, Sticker Maker, TTS Studio, etc.), please send an email directly to the repository owner instead of creating a public issue. 

**What to include:**
* A description of the vulnerability.
* Steps to reproduce the issue.
* Any potential impact or risk you have identified.

**What to expect:**
* We will acknowledge receipt of your vulnerability report within 48 hours.
* We will send you regular updates on our progress in addressing the vulnerability.
* Once the issue is resolved, we will notify you and (with your permission) credit you in the release notes.

Thank you for helping keep CamTech secure!
